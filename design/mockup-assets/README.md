# Mockup Assets

Took screenshots in zen browser w 4:3 aspect ratio using rectangle, with 1280 x 960 dimensions.
Used https://www.magicpattern.design/tools/mesh-gradients for bg, 4 color palette, 2 middle colors are bg (black/white). Grain at 10% (noise image, darken) blur at 50%.
other colors are pulled from finding dominant colors in the original screenshots using https://www.imgonline.com.ua/eng/get-dominant-colors.php.
